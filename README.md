## FluidInjector - Experimental

Idée de base: pouvoir créer des liquides avec des textures customs en injectant le liquid dans le registre interne de minecraft FLUID

## Ce qui bloque : 
- Minecraft code en dur les textures des liquides dans le client (ref: https://mcsrc.dev/2/26.2/net/minecraft/client/renderer/block/FluidStateModelSet#L14).
### Conclusion :
Impossible de pouvoir appliquer une texture via resourcepack pour faire un 3eme liquide par exemple 

Testée en **26.2**
